# 5G Fundamentals

[Deutsche Fassung](#deutsch)

## English

This document is a study outline for the lab. It will grow into a set of notes supported by standards references and controlled experiments.

### Topics

- 5G system architecture and the service-based core.
- 5G Standalone (SA) versus Non-Standalone (NSA).
- User Equipment (UE), gNodeB and the 5G Core.
- Radio Access Network and core-network responsibilities.
- Control plane and user plane.
- Registration, authentication and PDU session concepts.
- Network slicing and quality-of-service concepts.
- Relevant 3GPP specifications and terminology.

### Study method

For each topic, record a short explanation, relevant specification references, a diagram where useful, and observations from the private lab. Clearly distinguish standardized behavior from implementation-specific behavior.

## Deutsch

Dieses Dokument ist ein Lernplan für das Labor. Es wird schrittweise zu einer Wissenssammlung mit Normenreferenzen und kontrollierten Experimenten ausgebaut.

### Themen

- 5G-Systemarchitektur und servicebasierter Core.
- 5G Standalone (SA) im Vergleich zu Non-Standalone (NSA).
- User Equipment (UE), gNodeB und 5G Core.
- Aufgaben von Radio Access Network und Kernnetz.
- Control Plane und User Plane.
- Konzepte von Registrierung, Authentifizierung und PDU-Sitzungen.
- Network Slicing und Quality of Service.
- Relevante 3GPP-Spezifikationen und Fachbegriffe.

### Lernmethode

Zu jedem Thema werden eine kurze Erklärung, relevante Spezifikationsverweise, bei Bedarf eine Grafik und Beobachtungen aus dem privaten Labor festgehalten. Standardisiertes Verhalten und implementierungsspezifisches Verhalten müssen klar unterschieden werden.
