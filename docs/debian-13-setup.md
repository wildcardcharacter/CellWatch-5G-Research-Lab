# Debian 13 Workstation Setup

[Deutsche Fassung](#deutsch)

## English

The lab workstation baseline is Debian GNU/Linux 13 (Trixie). This checklist will be expanded as the actual system is prepared.

- [ ] Apply system updates and reboot if required.
- [ ] Record kernel, CPU, memory and available storage.
- [ ] Install Git and basic build tools.
- [ ] Set up a dedicated project workspace.
- [ ] Install and verify UHD when the USRP B210 is available.
- [ ] Verify USB 3 connectivity and host performance.
- [ ] Install analysis tools as needed.
- [ ] Create a private location for captures, logs and credentials.
- [ ] Ensure private data directories are excluded from Git.

Do not copy secrets, raw subscriber data or private captures into this repository.

## Deutsch

Die Basis des Laborrechners ist Debian GNU/Linux 13 (Trixie). Diese Checkliste wird während der tatsächlichen Einrichtung erweitert.

- [ ] System aktualisieren und bei Bedarf neu starten.
- [ ] Kernel, CPU, Arbeitsspeicher und verfügbaren Speicherplatz dokumentieren.
- [ ] Git und grundlegende Build-Werkzeuge installieren.
- [ ] Einen eigenen Projektarbeitsbereich einrichten.
- [ ] UHD installieren und prüfen, sobald die USRP B210 verfügbar ist.
- [ ] USB-3-Verbindung und Host-Leistung überprüfen.
- [ ] Analysewerkzeuge nach Bedarf installieren.
- [ ] Einen privaten Speicherort für Mitschnitte, Logs und Zugangsdaten anlegen.
- [ ] Sicherstellen, dass private Datenverzeichnisse von Git ausgeschlossen sind.

Geheimnisse, reale Teilnehmerdaten und private Funkmitschnitte gehören nicht in dieses Repository.
